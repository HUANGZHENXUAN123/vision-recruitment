# 任务一：蓝色装甲板灯条检测

## 运行

```bash
python task1_lightbar/detect_video.py <输入视频> <输出视频>
```

示例：

```bash
python task1_lightbar/detect_video.py task1_lightbar/input.mp4 task1_lightbar/output/lightbar_result.mp4
```

程序逐帧完成 HSV 蓝色分割、B-R 通道差分、形态学处理、轮廓提取和旋转矩形筛选，并在结果视频中标注帧号、灯条数量和处理耗时。

## 当前参数

- HSV：`(80, 120, 110)` 至 `(135, 255, 255)`
- B-R 差分阈值：`40`
- 形态学核：`1×1`（保留该步骤用于实验对比，当前配置等效于不改变掩膜）
- 轮廓面积：`3` 至 `100000`
- 长宽比：`1.5` 至 `20.0`

## 验收材料

- `representative_frames/`：原图、B/G/R、灰度、两组形态学对比、原始轮廓、多边形近似和旋转矩形结果。
- 输入视频和完整标注视频体积较大，不纳入 Git；提交时通过外部下载链接提供，并在根 README 中注明。

## 边界处理

- 输入路径不存在时给出提示并退出。
- 视频无法打开或输出视频无法创建时给出提示并退出。
- 视频结束或空帧时正常结束。
- 无有效灯条时写入 `lightbars=0`，不依赖固定坐标、固定帧号或固定目标数量。
